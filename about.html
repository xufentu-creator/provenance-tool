About

A small tool for clearer file continuity.

Provenance Tool is a free, local-first, open-source PWA for creating portable file provenance and integrity records without automatically uploading source files.

Why it exists

Files are easily copied, renamed, repackaged, and separated from their version information. This tool provides a compact public record that keeps calculated file facts, user-supplied statements, and tool identity distinguishable.

Public utility

Create, verify, and compare portable records in a browser.

Research origin

Developed by Xufen Tu as a public implementation related to human judgment, provenance, version continuity, and responsibility boundaries.

What remains outside this tool

The public application does not publish or implement private research reasoning, organizational governance methods, scoring systems, client workflows, or commercial decision processes.

Explicit boundary

The tool records calculations and declarations. It does not independently establish legal authorship, originality, ownership, identity, or a certified publication time.
