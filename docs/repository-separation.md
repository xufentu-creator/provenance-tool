# Repository Separation

Provenance Tool is maintained as a dedicated tool repository.

Earlier provenance tool records were created during the stage when tool materials and public research identity materials were maintained together.

Current and future Provenance Tool releases are maintained in this repository.

---

## Repository Roles

| Repository | Role |
|---|---|
| `provenance-tool` | Public browser-based tool, tool code, documentation, and releases |
| `xufentu-human-judgment` | Public research identity, publication references, and research continuity records |
| `judgment-as-structural-constraint` | Private research structure, model layer, and internal continuity records |

---

## Public Tool Repository

This repository maintains:

```text
tool code
public README
usage documentation
generated record documentation
release notes
security information
rights information
example records
```

---

## Public Research Identity Repository

The public research identity repository maintains:

```text
public research identity
publication references
ORCID and DOI references
public research continuity records
public provenance anchor
```

The public research identity repository may reference the existence of the Provenance Tool, but it does not need to present the tool as a main public homepage module.

---

## Private Research Repository

The private research repository may record the relationship between research models and tool directions.

It does not need to publish tool code or public user-facing tool pages.
