# Contributing

Bug reports, accessibility fixes, compatibility improvements, and focused documentation corrections are welcome.

## Privacy

Do not upload private source files, customer records, personal data, unpublished research, or real provenance packages to public issues. Use neutral reproductions.

## Scope

This repository contains the public reference implementation only. Contributions should remain narrowly related to local record creation, verification, version comparison, accessibility, security, and interoperability.

## Official releases

Only releases published by the canonical project repository are official. Forks and modified distributions must identify themselves accurately.
