Use cases

For files that need a clearer version story.

The tool is useful when a portable integrity record adds clarity without requiring an account or cloud upload.

Research manuscripts

Record a manuscript, supplements, and declared release metadata before public distribution.

Datasets

Create a compact record of files included in a dataset release.

Software releases

Preserve file-level hashes and version identity for a release archive.

Creative and project archives

Record a selected set of source files before transfer or publication.

Bilingual releases

Keep related language versions inside one portable package.

Version comparison

Identify file additions, removals, and changes between two selected sets.

Not a substitute

It is not a substitute for legal advice, identity verification, copyright registration, trusted timestamping, digital signatures, or institutional records management.
