# Changelog

## v0.4.2 — 2026-07-30

- Added automatic, editable title suggestions from selected file or folder names.
- Added automatic, editable date suggestions from file modification metadata.
- Added a compact result card.
- Added a human-readable summary matching copied record information.
- Added `RECORD-SUMMARY.txt` to generated packages.
- Added package-manifest verification.
- Added public About, How it works, Use cases, FAQ, Citation, and Privacy pages.
- Added structured software metadata, `robots.txt`, `sitemap.xml`, `llms.txt`, and `codemeta.json`.
- Updated the canonical tool URL to `https://research-tools.xufentu.com`.
- Improved PWA cache handling and mobile usability.

## v0.4.0

- Added installable, offline-capable PWA support.
- Added portable provenance ZIP packages.
- Added local file verification and file-set comparison.
